ELC 电量监视 · 界面设计规范

桌面托盘工具 · 440px 无边框窗口 · WPF / .NET 8 · 亮暗双主题

01设计原则

这是「低头看一眼就走」的工具，不是需要停留的仪表盘。四条原则决定后面所有取舍：数字优先（数值是主角，其余全部退让）、状态可辨（颜色+图标+文字三重编码，不靠色相单独承载语义）、零学习（Windows 用户对列表、开关、分段控件的预期照搬，不发明交互）、一眼全局（多设备时最紧张的那台必须立刻被看到）。

02核心界面

三屏并列。主界面在 440px 内可容纳 3 台设备而不滚动；设置独立成页，用标题栏的返回箭头出入，不再与列表共用同一块空间。

03色彩系统

只有一套强调色（蓝，用于可点击）和一套状态色（绿/琥珀/红，只用于数值与状态标记）。状态色一律不用于按钮和链接，避免「红色按钮」被误读为危险操作。

accent#2563EB / #5B9DFF可点击 · 主按钮
success 充足#14804A / #45D48E≥50% 或充满
caution 偏低#A9640C / #E8A33D20–49%
danger 危险#C0392B / #F0736A<20% 或读取失败
window bg#F7F8FA / #16181C窗口底
surface#FFFFFF / #1E2127卡片面
text primary#14161A / #EDEFF3设备名 · 数值
text tertiary#8A929E / #7C8492仅辅助信息，≥3:1
对比度实测（WCAG AA = 4.5:1 / 大字 3:1）
  • #14161A on #FFFFFF → 16.8:1 · 正文与数值，AAA
  • #5F6875 on #FFFFFF → 6.4:1 · 副信息，AA
  • #14804A on #FFFFFF → 5.5:1 · 绿色数值，AA
  • #A9640C on #FFFFFF → 5.1:1 · 琥珀数值，AA
  • #C0392B on #FFFFFF → 6.0:1 · 红色数值，AA
  • #2563EB on #FFFFFF → 5.2:1 · 链接与主按钮文字，AA
  • #8A929E on #F7F8FA → 3.1:1 · 仅用于 12px 辅助信息（非关键信息），不承载状态语义
深色主题对应数值：#EDEFF3 on #1E2127 = 13.2:1 · #45D48E = 8.1:1 · #E8A33D = 7.6:1 · #F0736A = 5.4:1 · #5B9DFF = 6.1:1

04排版与度量

字体栈Microsoft YaHei UI → Segoe UI Variable → Segoe UI。中文优先雅黑，数字跟随西文字体获得更好的 tabular 对齐。
数值 27px / 600卡内百分比，行高 1，字距 −0.5px，FontNumeralAlignment=Tabular。刷新时数字不跳宽。
设备名 14px / 600单行，TextTrimming=CharacterEllipsis，与数值同行两端对齐。
副信息 12px / 400连接方式、更新时间、状态说明。颜色 --text-2。
分组标题 11px / 600设置页分组，色 --text-3，字距 0.6px。
间距 4pt 基准4 / 8 / 10 / 12 / 16 / 20 / 24。卡内 13–15，卡间 9，分组间 14。
圆角窗口 14 · 卡片 14 · 输入与分段 8 · 开关 9（胶囊）· 进度条 4。
描边一律 0.5px。常规 --border，强调 --border-strong，未适配卡片用 0.5px dashed。
进度条高 8px，轨道 --track，填充语义色。预警刻度：2px×13px 竖线置于阈值百分比位置，超出轨道上下各 2.5px。
窗口440×自适应，最小 380×360，最大高度 620 后卡区滚动。圆角由 DWM 提供（Win11），Win10 回退 14px 纯色。

05组件与状态

组件尺寸规范
窗口按钮28 × 28圆角 8，默认透明，hover rgba(128,136,152,.14)，press 加深至 .22。图标 15px、1.4px 描边、圆头端点。关闭按钮 hover 不染红（与 Windows 应用一致，避免误触焦虑）。
设备卡片440 − 32 paddingpadding 13/15，圆角 14，margin-bottom 9。四行结构：名称+数值 → 进度条 → 副信息+状态 → （可选）错误。
状态标记12px图标 10–11px + 文字，字形与数值同色。仅在需要提醒时出现（偏低/危险/充电中/无应答），正常状态留空 —— 空比「正常」更安静。
分段控件高 24，内 padding 2容器 --seg-bg 圆角 8，选中项白底 + 0.5px 描边 + 600 字重，未选中 --text-2、400。
开关32 × 18胶囊轨道，圆点 14px 内距 2px。关闭态轨道 --seg-bg，开启态 --accent，位移 200ms ease。
步进器高 24− 值 + 三段，边框 0.5px 圆角 8。单击 ±1，长按 400ms 后连续步进，Shift 单击 ±5。阈值范围 5–50% 且一级 > 二级。
空状态居中，最大宽 250线稿插画（非彩色）、主文案 14/600、说明 12px 两行内、主操作描边按钮。不做整屏灰化，保留标题栏可用。
未适配卡片同设备卡片虚线边框、无进度条（改用虚线空槽）、数值位显示 --、右下文末操作「导出报告」。刻意降低视觉权重，但不隐藏。

06交互与动效

键盘
  • Ctrl + R 立即刷新 · Esc 设置页返回 / 主界面最小化到托盘 · Ctrl + , 打开设置
  • Tab 顺序：窗口按钮 → 设备卡片（可聚焦，Enter 查看详情）→ 底部刷新。焦点环 2px --accent + 2px offset，始终可见（不使用 :focus-visible 之外的抑制）
  • 触控目标全部 ≥ 28×28；步进器按钮 24×24 为桌面端可接受下限，不与触屏共用
动效
  • 视图切换（主 ↔ 设置）：内容区横向位移 16px + 透明度，180ms cubic-bezier(.2,0,0,1)。不做整窗缩放
  • 数值变化：数字直接替换，不做滚动动画（电量刷新频繁，动画会变成噪音）
  • 进度条变化：宽度 240ms ease-out；语义色变化用 120ms 交叉淡入，避免红绿闪烁
  • 刷新反馈：图标旋转一圈 600ms，仅手动触发时；自动刷新不显示任何动画
  • 尊重系统「减少动画」设置，全部降级为瞬时切换
反馈时机
  • 读取失败：卡片内 -- + 副信息说明原因，不用弹窗。连续 3 次失败才升为托盘气泡一次
  • 点关闭 → 最小化：首次执行时弹一次性气泡「已最小化到托盘，点击图标可打开」，之后静默
  • 保存设置：按钮文字变为「已保存」600ms 后复原，不弹对话框

07WPF 实现要点

问题做法
主题切换把现有 App.xaml 里的画笔改为 DynamicResource（当前是 StaticResource，切换不会生效），两套 ResourceDictionary 装在 Themes/ 下运行时替换 MergedDictionaries。
数值不跳宽Typography.NumeralAlignment="Tabular" 加在 TextBlock 上；雅黑回退时用 Segoe UI 单独渲染数字。
图标放弃 ⟳ ⚙ — ✕ 字符，改用 Path Data（Geometry）。字符图标在不同 DPI 下基线漂移，且无法控制描边粗细。
预警刻度进度条 ControlTemplate 里加一条 Border，HorizontalAlignment=Left + Margin 绑定阈值计算值；或在 Grid 上用 ColumnDefinition Width="*" 双列按百分比分配。
视图切换主视图与设置页放在同一 Grid 的两个 Grid 层，切换时对 TranslateTransform.X 与 Opacity 做 DoubleAnimation；不要用两个 Window。
分段控件 / 开关WPF 无原生控件。分段控件用 ListBox + 自定义 ItemContainerStyle；开关用 ToggleButton + 自定义 Template（Track + Thumb）。
滚动与高度窗口 SizeToContent=Height 会与最大化冲突，改用代码设置 Height = min(内容高, 620)，内容超出时 ScrollViewer 接管。
落地顺序建议
  • 第一步（收益最大）：状态语义色 + 图标替换 + 数值 tabular + 预警刻度。只改样式，不动结构，视觉提升最明显。
  • 第二步：设置页拆成独立视图 + 分组卡片 + 分段控件/开关，替换掉裸 TextBox 和 ComboBox。
  • 第三步：暗色主题 + 空状态插画 + 未适配卡片形态。
  • 可省略：窗口背景图与不透明度（与状态色叠加会破坏对比度），建议从设置里移到「高级」或直接移除。
